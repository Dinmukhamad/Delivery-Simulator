# Проверка Delivery Simulator Demo 0.16.0

Добавлен воздушный бой самолётов. ЛКМ — огонь по курсу: 100 HP, 25 урона, четыре попадания, дальность 160 м и интервал 250 мс. Оба самолёта должны быть заняты и находиться от 2 м над землёй. Стены закрывают цель от огня. Host проверяет поколение транспорта, темп стрельбы, цель и урон; клиент не передаёт цель или величину урона.

Сбитый курьер возвращается к гаражу. Карьерный профиль и посылка сохраняются; уже купленный самолёт можно вызвать снова бесплатно. Воздушный счёт относится только к смене и не выдаёт деньги/XP за доставки.

Проверка сборки 0.16.0 выполняется. Фактический результат CI и ссылки на архивы будут добавлены после завершения, без изменения проверенного исполняемого кода.

Предыдущая подтверждённая версия 0.15.0: [run 39424298323](https://github.com/Dinmukhamad/Delivery-Simulator/actions/runs/39424298323), 11720 проверок и 27 рендеров. Это исторические результаты, не результат новой сборки.

CI использует Linux Godot 4.6.3. Проверка точных Windows/macOS PCK подтверждает код и ресурсы; нативный запуск Windows EXE/macOS приложения, физическая смешанная LAN и FPS требуют ручной приёмки. macOS не нотарифицирована.
