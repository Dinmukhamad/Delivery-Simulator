# Проверка Delivery Simulator Demo 0.12.0

Проверка события «Обеденный час» и экспорт Windows/macOS выполняются в GitHub Actions. Итоговые результаты, архивы и снимки будут добавлены после завершения проверки.

Событие работает по одним правилам в Solo и LAN: первый запуск через 45 секунд смены, длительность 180 секунд, перерыв 300 секунд. В деловом районе появляются до трёх дополнительных заказов из кафе в офисы. Host проверяет принятие, доставку и бонус 50%. После конца события принятые заказы остаются выполнимыми за обычную оплату.

План проверки включает прежние группы навигации, города, обычных заказов и Team Shift; новую группу времени/наград/сохранения/передачи событий; четыре сценария настоящего двухпроцессного ENet; реальные рендеры экранов 1280×720 и 960×540. Новая группа правил также запускается с точными Windows и macOS PCK после экспорта.

## Пределы проверки

CI использует Linux-редактор Godot и программный OpenGL. Проверка экспортированных PCK подтверждает код и ресурсы, но не является нативным запуском EXE или macOS-приложения. Совместный LAN на 3–4 физических Windows/macOS-устройствах, FPS и слышимость звуков требуют ручной приёмки. macOS-сборка не нотарифицирована. Это согласованная отдельная Godot-демоверсия.

Предыдущая версия 0.11.0 прошла 5358 проверок: [сборка 38325332235](https://github.com/Dinmukhamad/Delivery-Simulator/actions/runs/38325332235). Эти результаты относятся к предыдущему игровому коммиту; они не заменяют проверку нового события.
